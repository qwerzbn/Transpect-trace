# 需求 2「大模型数据外发实时拦截」进展

日期：2026-10-12

## 进展

Codex 客户端（命令行和桌面版）与 Claude Code 的流量抓取都已实现，可以拿到它们发给模型服务的完整请求明文和流式返回。

## 实现方式

把客户端的模型地址改到本机 Gateway：客户端先把请求明文发给 Gateway，Gateway 记录完整正文后，再用 TLS 转发给模型服务。这样不需要在旁路破解 TLS，Windows 和 Linux 上都已验证，Mac 的测试步骤已写好，待实测。

## 未完成

- 拦截只有原型：能在转发前按预设规则返回 403，还不能识别代码、密钥和个人信息。
- 改模型地址后客户端要用项目的 API Key，不能保留原来的账号登录；保留登录时的抓取需要 HTTPS 中间人代理，尚未开始。
